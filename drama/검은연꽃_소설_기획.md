# 검은 연꽃 — 소설 기획안

## 어떤 책으로 낼까: 두 가지 길

| | 웹소설 연재 | 장편소설 출간 |
|---|---|---|
| 형식 | 회당 5,000자 안팎, 100~150화 | 원고지 1,000~1,500매, 2~3권 |
| 문체 | 연의 1인칭, 짧은 문장, 회마다 끝에서 끊기 | 1인칭 + 견의 시점 장 교차, 묘사 깊게 |
| 어디에 | 네이버 시리즈·카카오페이지·문피아 (공모전 → 계약) | 출판사 투고, 역사소설 공모 |
| 장점 | 반응 보면서 쓰고, 드라마와 서로 홍보가 됨 | 작품성 인정, 판권 판매(드라마화)에 유리 |

**추천:** 웹소설로 먼저 연재하세요. 대본이 이미 있으니 속도가 빠르고, 독자 반응이 드라마 기획의 근거가 됩니다. 반응이 좋으면 단행본은 따라옵니다.

## 소설에서만 할 수 있는 것

1. **연의 속마음:** 영상에서는 옅은 미소 하나로 끝나는 장면을, 소설에서는 그 미소 뒤의 계산과 죄책감까지 다 보여줄 수 있어요.
2. **견의 시점 장:** 몇 장마다 견의 시점을 넣어요. 연을 지켜보는 6년, 선죽교, 정몽주에 대한 죄책감.
3. **실록 인용으로 장 시작하기:** 각 장 첫머리에 실제 실록 한 줄을 두고, 그 뒤에 숨은 이야기를 풀어요. 기획 의도인 "실록의 틈"이 형식으로 드러납니다.

## 5부 구성 (2026-10-29 개편)

- **프롤로그 「임진강」 (1376):** 반야의 수장을 열두 살 견이 목격
- **1부 「바다에 던져진 이름」 (1388~1395)**
- **2부 「피의 밤」 (1395~1402)**
- **3부 「끝없는 늪」 (1402~1410):** 조사의의 난 뒤의 연, 태조의 철퇴, 한씨 상궁의 죽음(원경이 먼저 침), 비 오는 산사, 죽어 가는 태조에게 이름을 밝히는 첫 복수, 둘째 수, 제주
- **4부 「검은 연꽃」 (1410~1422):** 첩지 거부, 원경의 반격(갑사의 씨), 성녕대군, 어리, 심온, 견의 도주와 오대산 자수, 태종 임종 앞의 고백, 연의 편지와 죽음
- **5부 「물 밑의 뿌리」 (1422~1460년대):** 휘·수의 양자 입적, 수의 집현전, 계유정난, 수의 손녀가 후궁으로(조선 왕실 속의 왕씨)

**심온 옥사 (1418, 4부) — 연이 뒤에 있음:** 심온이 사은사로 떠나는 날 전송 인파로 도성이 비자, 연이 그 행렬을 세어 상왕(태종)에게 올림. 민무구 형제 때와 같은 셈. 강상인 옥사가 심온에게 이어지고 심온은 사사, 부인 안씨와 딸들은 관비가 됨. 연은 자기를 "작은 이름"이라 알아봐 준 유일한 사람(충녕)의 처가를, 자기 가족이 당한 것과 똑같이 무너뜨림 → 흑련이 완성되는 지점. 소헌왕후의 눈물을 연이 수라간에서 지켜봄. 5부에서 세종이 이 일의 뒤에 연이 있었음을 알게 되고, 그럼에도 수를 거두는 것이 세종의 인과응보이자 용서.

**4부 1417~1418 흐름 (2026-10-29 확정):** 한씨 상궁 죽음(3부 26장) → 연이 양녕에게 어리를 붙임(사냥 뒤 수라간에 온 양녕을 대접하며 측근에게 곽선의 첩 소문을 흘림) → 성녕대군 천연두(1418.2), 연이 살릴 길(두창을 앓고 산 민간 의원)을 알고도 부르지 않음 = 원경이 한씨 상궁을 가져간 값 → 양녕 폐위(1418.6) → 심온 옥사(1418 겨울).
- 연이 양녕에게 "전하와 중궁마마께서 충녕대군을 마음에 두고 계십니다"라고 흘려, 양녕이 더 미쳐 날뛰게 만듦(사냥·월담·어리 집착이 심해짐).
- 양녕은 연이 아버지의 여자라는 것을 알고 "전하의 시녀는 다 궁에 들이시면서" 상소를 씀. 공부는 안 했지만 사람 보는 눈은 있는 양녕. 연과 양녕이 서로를 알아보는 대면 장면 필요.

**양녕의 긴 그림자 (5부):** 연은 1422년 무렵 죽고 양녕은 1462년까지 삶. 연이 죽기 전 양녕에게 남긴 말("충녕의 자식들은 당신을 끝까지 세지 않을 거예요")이 30년 뒤 계유정난 때 양녕이 수양 편에 서서 안평·단종을 죽이라 간청하는 씨앗이 됨 → 연은 죽어서도 이씨 왕가가 서로 죽이게 함. 양녕의 임종(1462)에 수가 찾아가고, 양녕이 "그 나인의 아들이로구나" 알아봄. "예장도 받지 말고 묘비도 세우지 말라"는 실제 유언이 이름 없이 산 연과 겹침.

**왕씨 수장 고증 (2026-10-29 확인):** 1394.4 강화 나루·거제 바다 투살은 『태조실록』 기록(배 마개 뽑기, 玉·全·田 개성은 야사 → 쓰지 않음). 대상은 공양왕 쪽 종친 중심, 백수십 명 규모.
- 태조가 이듬해 왕씨를 위한 수륙재를 지냄 → 22장 염주 장면과 연결, 4부 또는 역사 메모에 "죽인 이들을 위해 재를 올리던 분" 한 줄.
- 문종 대 숭의전·왕씨 후손 찾기 → 5부에서 휘·수의 외가가 왕씨라는 사실이 드러날 뻔하는 장면. 이름 없이 살아남은 왕씨의 피를 밝힐지 숨길지가 5부의 갈림길.

**정몽주의 마지막 외침 (1부 4장 선죽교, 2026-10-29 추가):** 철퇴를 맞고 무릎으로 일어나 "방원이 네 이놈!" — "네 자식들이 네게서 무엇을 배우겠느냐." 견이 이 목소리를 기억 → 4부 태종 임종 장면에서 견 또는 연이 이 말을 되돌려 줄 수 있음.

**연·견 감정선 보강 (1·2부에 삽입 예정):** 산사의 열병 간호, 장독대 살구씨 기름, 석보가 죽던 밤 연이 견을 간호, 승은 다음 날의 부끄러움, 방원의 처소 앞에서 피 맺히는 견의 손, 무릎 꿇고 멈춰 달라 비는 견

## 첫 문장 후보

- "나는 내 가족을 바다에 던진 사내의 아이를 낳았다." *(로그라인 그대로. 제일 강해요)*
- "그날 바다는 이상하리만치 잔잔했다."
- "아버지는 내 손바닥에 王 자를 쓰셨다. 나는 평생 그 손을 펴지 않았다."

## 4·5부 완성 (37~46장) 요약
- 37 심온: 연이 서대문 밖 전송 인파를 세어 상왕에게 보고 → 심온 사사, 세종 "나는 잊지 않는다"
- 38 오대산: 원경이 김포 의녀로 셈을 맞춰 상왕에게 고발 / 칠패 부엌의 마지막 밤("연." 이름을 처음 부름, 손바닥에 夫) / 견 자수·침묵 → 경원 정병, 상왕 "찾지 마라"
- 39 임종: 원경 "오래 살아서 다 세고 가거라" / 태종 "너는 왕씨지, 네가 내 수륙재였다" / 휘=이월, 수=삼월, '휘' 이름을 처음 소리 내어
- 40 검은 연꽃: 세종이 출궁 허락("연. 그게 맞는 크기로구나"), 수에게 편지, 서지 연못에서 붉은 댕기를 땋고 웃으며 죽음
- 41 편지: 수가 편지를 읽고 경원으로, 夫 전달, "아버지"
- 42 양자: 세종이 내관 통해 강릉 최 진사 입후(최수), 휘는 산에 남음
- 43 집현전: 태종실록을 보지 않은 세종과 수의 밤 대화 / 견 사망(1433), 蓮·夫 종이, 무덤 앞 土→王
- 44 누구나 쓰는 글: 훈민정음, 올케가 열흘 만에 '아씨'를 씀, 서지에 '련'
- 45 다시 피의 밤: 숭의전 왕씨 장부에서 자기 이름 빼기 / 계유정난, 양녕이 수양 곁에 / 영월 단종, 무명의 재
- 46 물 밑의 뿌리: 수의 손녀 '련'(성종 후궁, 가공) 1인칭, 양녕 임종·세조 상원사 일화, 은 연꽃 7번째 손
