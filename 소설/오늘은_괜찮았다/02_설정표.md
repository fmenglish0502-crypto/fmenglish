# 《오늘은 괜찮았다》 설정표

## 1. 인물

### 김지은 (A) — 화자

| 항목 | 내용 |
| --- | --- |
| 나이 / 일 | 서른넷. 식품회사 고객상담팀 대리. 9년 차 |
| 사는 곳 | 서울 망원동, 볕이 잘 드는 3층 빌라 투룸. 감자와 9년을 살았다 |
| 가족 | 부모는 중학생 때 이혼. 어머니는 재혼해 창원에 산다. 명절에 통화하는 사이. 스스로 가족이라 부르는 존재는 감자뿐 |
| 겉 | 감정이 얼굴에 다 드러난다. 잘 울고, 잘 말하고, 힘들면 힘들다고 한다 |
| 속 | 자기가 감정에 솔직하니 남들도 그럴 거라고 믿는다. 말하지 않는 것은 없는 것이라고 생각해 왔다 |
| 감자의 죽음 뒤 | 집에 들어가지 못한다. 밥을 먹다 목이 막힌다. 모텔에서 열이틀, 수진의 집에서 한 달을 지낸다 |
| 회복의 방식 | 슬픔을 말로 옮긴다. 사진을 보여 주고, 울고, 이야기한다. "사랑했기 때문에 아프다"는 문장에 도달한다 |
| 3막의 질문 | 사랑했는데 왜 몰랐을까. 막을 수 있었을까. 나는 그날 무엇을 보았던 걸까 |
| 변화 | 타인의 "괜찮아"를 듣는 방식이 달라진다. 답은 얻지 못한다 |

**주의:** 지은은 '건강한 정신을 가진 사람'의 표본이 아니다. 무너지는 사람이다. 지은에게 있는 것은 강함이 아니라, 슬픔에 대상이 있고 그것을 말할 수 있으며 들어 줄 사람이 있었다는 조건이다.

### 이수진 (B)

| 항목 | 내용 |
| --- | --- |
| 나이 / 일 | 서른넷. 물류회사 인사팀 과장. 일 잘한다는 평을 듣고, 실제로 잘한다 |
| 사는 곳 | 서울 성산동, 15평 아파트 전세. 지은의 집에서 차로 10분. 거실에 화분이 많다 |
| 가족 | 부모는 대전. 세 살 아래 동생 수호. 사이가 나쁘지 않다. 그래서 더 말하지 못한다 |
| 겉 | 친구 생일을 기억하고, 맛집 목록을 지도 앱에 저장해 두고, 여행 계획을 엑셀로 짠다. 농담을 잘하고 남의 고민을 잘 듣는다. 가끔은 정말로 크게 웃는다 |
| 속 | 씻고, 먹고, 출근하는 일을 매일 의식적으로 해낸다. 휴대폰에 알람이 열네 개 있다. 혼자 있는 휴일에는 불을 켜지 못하고 누워 있는 날이 있다 |
| 병 | 서른 살 겨울에 처음 정신건강의학과에 갔다. 주요우울장애 진단. 4년째 외래 치료와 약 복용. 3주에 한 번, 토요일 오전 진료 |
| 아는 사람 | 수호만 "누나가 병원 다닌다"는 정도로 안다. 지은은 모른다. 회사에도 말하지 않았다 |
| 왜 말하지 않았나 | 숨긴 것이 아니다. 처음엔 말할 때를 놓쳤고, 나중엔 설명할 말을 찾지 못했다. "왜 힘든데?"라는 질문에 댈 이유가 없어서 |
| 내면의 문장 | 죽고 싶다는 생각을 종일 하는 사람이 아니다. 살아야 한다는 사실을 매일 아침 자신에게 다시 설득해야 하는 사람이다 |
| 삶을 붙잡는 것들 | 토요일 병원 예약, 화분 물 주는 날, 지은, 수호, 야구 예매, 9월 강릉 숙소 예약. 수진은 이것들을 일부러 달력에 심어 둔다 |
| 음료 | 술을 마시지 않는다. 주변에는 "운전해야 해서", "요즘 위가 안 좋아서"라고 말한다 |

**주의:** 수진의 웃음은 가면이 아니다. 지은을 돌보는 일도 연기가 아니다. 수진은 남을 돌볼 때 실제로 조금 나아지는 사람이고, 그것이 수진의 진심이면서 수진을 지치게 하는 것이기도 하다. 소설은 둘 중 하나로 정리하지 않는다.

### 이수호 — 수진의 동생

서른하나. 대전에서 부모와 가까이 산다. 중학교 체육교사. 누나가 병원에 다닌다는 것을 2년 전 우연히 약 봉투를 보고 알았다. "괜찮아, 감기 같은 거야"라는 누나의 말을 믿었다. 3막에서 지은에게 수진의 이야기를 들려주는 사람이자, 지은과 같은 질문을 다른 방향에서 붙들고 있는 사람. 지은이 자책을 독점하지 못하게 한다.

### 박민서 — 지은의 회사 후배

스물일곱. 고객상담팀 2년 차. 1막에서는 지은의 빈자리를 메워 주는 싹싹한 후배로 두어 번 지나간다. 24장면에서 "괜찮아요"라고 말하는 사람. 민서에게 실제로 무슨 일이 있는지는 끝까지 밝히지 않는다.

### 그 밖의 인물

| 인물 | 역할 |
| --- | --- |

| 수진의 주치의 | 10장면. 3분 남짓한 진료. 차갑지도 따뜻하지도 않은, 성실한 사람 |
| 정 선생 | 21장면 자조모임에서 만나는 오십대 여성. 남편을 잃은 지 6년. 본인도 우울증 치료를 받으며 살아간다. 답을 주지 않고, 답이 없는 채로 사는 모습을 보여 준다 |
| 수진의 회사 후배 | 16·18장면. 수진에게 고민 상담을 하던 사람. 장례식장에서 "과장님이 저를 붙잡아 주셨는데"라고 말한다 |

### 감자

아홉 살. 치즈태비 수컷. 지은이 스물다섯 살 겨울, 첫 직장 근처 감자탕집 뒤에서 데려왔다. 창가 캣타워 맨 위 칸에서 볕을 쬐는 것이 일과. 지은이 퇴근하면 늘 현관에 나와 있었다. 사인은 비대성 심근병증으로 인한 급사로 추정. 전날까지 잘 먹고 잘 놀았다.

## 3. 공간

| 공간 | 묘사의 핵심 |
| --- | --- |
| 지은의 집 | 남서향. 오후 세 시면 거실 창으로 볕이 길게 들어온다. 창가 캣타워. 1막에서는 들어갈 수 없는 곳, 3막에서는 수진의 화분이 놓이는 곳 |
| 수진의 차 | 흰색 준중형. 조수석 햇빛가리개에 주차권이 꽂혀 있다. 지은은 늘 조수석에만 앉았다 |
